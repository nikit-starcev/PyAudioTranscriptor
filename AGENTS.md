# AGENTS.md — PyAudioTranscriptor

Правила и конвенции для агентов, работающих с этим репозиторием.

## ПРАВИЛО: перезапуск web-сервера

**Перед ЛЮБЫМ перезапуском web-сервера всегда проверять состояние и не прерывать активный прогон молча.**

1. Проверить, запущен ли сервер:
   `curl -s --max-time 3 localhost:8790/api/health` (и/или PID из `/tmp/opencode/web.pid`).
2. Проверить наличие активного прогона:
   `curl -s localhost:8790/api/jobs` → есть ли задачи в статусе `running`/`queued`.
3. **Если прогон есть — сначала СПРОСИТЬ пользователя, можно ли перезапускать**
   (перезапуск прервёт задачу). Не перезапускать молча.
4. Только при отсутствии активных прогонов (или после явного подтверждения) —
   перезапуск:
   ```bash
   setsid nohup .venv/bin/audio-transcriber web --no-browser --port 8790 >> /tmp/opencode/web-server.log 2>&1 &
   echo $! > /tmp/opencode/web.pid
   ```
   Обычный `nohup ... &` иногда умирает при завершении вызывающего процесса —
   использовать `setsid`.
5. Порт — `8790` (порт `8765` занят MCP `sequentialthinking`).

## Конвенции проекта

- **TODO ↔ issues**: `TODO.md` синхронизирован 1:1 с GitHub issues. Открытый пункт
  содержит `(#N)`; при завершении — закрыть issue (комментарий + `state=closed`) и
  перенести пункт в раздел «Сделано (недавнее)». Якорь вставки там —
  `## Сделано (недавнее)`, а не `## Сделано`.
- **Версия** — `hatch-vcs` из git-тега. После новых коммитов метаданные обновляются
  только переустановкой: `uv pip install -e . --no-deps` (иначе `/api/health` и
  `importlib.metadata` показывают устаревшую версию до релиза).
- **Секреты** (HF-токен, GitHub PAT) — только в `config.env` / секретах веба;
  никогда не коммитить и не сохранять в память.
- **Релизы** — см. `RELEASING.md`: CHANGELOG (`## [X.Y.Z] - дата`) → коммит →
  аннотированный тег `vX.Y.Z` → push тега → GitHub Actions создаёт Release.
- **Тесты/линт** перед коммитом: `.venv/bin/python -m pytest -q`,
  `.venv/bin/ruff check src tests`, `.venv/bin/mypy`.
- **Движок диаризации `nemo-speech`** (бандл `nemo-speech-native/`): из `lib/`
  обязательно удалены `libstdc++.so.6` и `libgcc_s.so.1` — иначе через
  `LD_LIBRARY_PATH` они затеняют системную библиотеку и Vulkan-ICD Radeon не
  грузится (GPU не находится).
