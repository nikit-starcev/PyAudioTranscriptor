# Тест-кейсы веб-UI (QA-прогон)

Ручные/полуавтоматические кейсы для проверки веб-интерфейса (`audio-transcriber web`).
Прогоняются в реальном браузере; по ходу фиксируются **баги**, **графические артефакты** и
**места для улучшения** → отдельными issue.

Формат записи результата: `TC-ID | PASS/FAIL | находка (репро + evidence: скриншот/консоль/сеть)`.

> Безопасность данных: прогон на **копии** `web-data` (свой инстанс/порт), либо read-only;
> мутирующие шаги (переименование, применение правок, загрузка) — только на копии.

## Как запускать
```bash
# копия данных + отдельный инстанс (пример)
cp -r web-data /tmp/opencode/qa-web-data
AUDIO_TRANSCRIBER_DATA_DIR=/tmp/opencode/qa-web-data \
  .venv/bin/audio-transcriber web --no-browser --port 8795
```
Браузер: Chrome for Testing (`/home/user/.cache/puppeteer/chrome/linux-154.0.8037.57/chrome-linux64/chrome`),
скриншоты на каждом шаге, `console`/`network` — на ошибки.

## A. Общее/Topbar/темы
- **TC-A1** Загрузка `#/jobs`, шапка, сайдбар: нет ошибок консоли; активный пункт подсвечен.
- **TC-A2** Переключение темы (Светлая/Тёмная/Авто) — применяется, без мигания, сохраняется после reload.
- **TC-A3** Узкая ширина (~380 px) и широкая: вёрстка не «рвётся», меню сворачивается.
- **TC-A4** Клавиатура: Tab/Enter по навигации, фокус виден; Esc закрывает модалки.
- **TC-A5** Русские длинные строки/имена: нет обрезки текста, перенос корректный.

## B. Задачи и файлы
- **TC-B1** `#/jobs`: список задач, статусы (done/running/…), открытие задачи.
- **TC-B2** Тумблер «Показать удалённые», восстановление/удаление навсегда.
- **TC-B3** Панель «Файлы»: загрузка, «В очередь» → задача стартует; оценки (`≈ N мин`, #107).
- **TC-B4** Тумблер «Обработанные» + «Вернуть» файл.

## C. Стенограмма и плеер
- **TC-C1** Рендер стенограммы: реплики, таймкоды, говорящие (в т.ч. наложения «Имя1 + Имя2»).
- **TC-C2** Поиск/фильтр по тексту.
- **TC-C3** ▶ у реплики — играет интервал `[start,end]`, автостоп.
- **TC-C4** Клик по слову (#119): играет **до конца реплики**, повторный клик — стоп; караоке-подсветка.
- **TC-C5** Клик по слову при выделении текста — воспроизведение НЕ стартует; ПКМ → «в глоссарий».
- **TC-C6** Автопрокрутка к активной реплике; уважение ручного скролла.

## D. Правки/редактор
- **TC-D1** «Проверить текст»: список предложений (орфография/частые), «Принять/Отклонить», применение.
- **TC-D2** Подсветка правок в тексте (#120): красным; клик по сводке → переход к месту + контекст.
- **TC-D3** Семантический блок (LLM): предложения (если есть sidecar), accept/reject.
- **TC-D4** Ручная правка реплики (#26): инлайн, бейдж «изменено», «сбросить», сохранение после reload.
- **TC-D5** Визуальные артефакты: наложения подсветок, «пробел–тире–пробел», переносы, контраст в тёмной теме.

## E. Говорящие
- **TC-E1** Панель «Говорящие»: список, счётчики реплик/наложений.
- **TC-E2** Переименование, слияние, «Применить имена» (enrollment), «Переопределить говорящих».
- **TC-E3** Инлайн-назначение говорящего в стенограмме (#59); «+ второй говорящий»/разделить (#78).
- **TC-E4** Дорожка говорящего (#108): плеер, скачивание m4a, «глушить наложения»; заглушение чужих интервалов.

## F. Стадии/прогресс
- **TC-F1** Вкладка «Стадии» у незавершённой задачи (#111); план стадий, проценты, ETA, «здоровье».
- **TC-F2** Живое обновление по SSE (#112); «Остановить» → `cancelled`.

## G. Чат/протокол/экспорт
- **TC-G1** Чат по стенограмме (#54): вопрос → стриминг, кликабельные цитаты → переход к таймкоду.
- **TC-G2** «Сформировать протокол»/резюме; шаблоны промптов (#97).
- **TC-G3** Экспорт (#18/#53): TXT/DOCX/JSON/SRT/VTT/MD/PDF — скачивается, кириллица в имени.

## H. Архив
- **TC-H1** `#/archive`: список по дням, карточка (дата/встреча/участники/заметки), сохранение.
- **TC-H2** Поиск (текст/говорящий/даты) → переход к реплике; пустой результат — понятный EmptyState.

## I. Модели/бинарники/голоса/глоссарий
- **TC-I1** `#/models`: статусы present/missing, размеры, скачать/удалить.
- **TC-I2** `#/binaries`: статусы, «Скачать все»/«Удалить все» (#115), прогресс.
- **TC-I3** `#/voices`: список, добавление, «Найти дубликаты» (#39), удаление.
- **TC-I4** `#/glossary`: список, поиск, добавление из выделения (#17), импорт.

## J. Настройки/мастер
- **TC-J1** `#/settings`: поля сохраняются, применяются к новой задаче; API-ключ (#110), тумблеры.
- **TC-J2** «Кэш обработки» (#100): размер, очистка (409 при активном прогоне).
- **TC-J3** `#/wizard`: готовность (модели/пакеты/бинарники) — статусы корректны.

## K. Кросс-проверки
- **TC-K1** Нет 4xx/5xx в network на штатных действиях.
- **TC-K2** Нет ошибок/варнингов в console на каждом экране.
- **TC-K3** Нет «графических артефактов»: обрезанные элементы, наложения, битые тени/границы, «прыжки» вёрстки.
