# Глоссарий терминов для LLM-постобработки.
#
# Формат: по одному термину в строке. Строки, начинающиеся с «#», и пустые
# строки игнорируются. Термин может быть одним словом (аббревиатурой или
# существительным) либо фразой из нескольких слов.
#
# Явные пары «как слышит ASR = канон» задаются в одной строке через «=»:
#   АИБ = ОИБ
# Слева — ошибочная форма, справа — канон. Такие пары применяются ВСЕГДА и
# приоритетнее нечёткого сопоставления — это безопасный способ гарантировать
# нужную замену, когда нечёткий поиск может быть неоднозначным (например,
# «АИБ» похоже сразу и на «ОИБ», и на «АИС»).
#
# Нечёткий матчер приводит ASR-опечатки терминов к канону, учитывает регистр и
# склонения, но точные термины не меняет, а короткие аббревиатуры правит
# только при единственном кандидате. Также предлагает новые термины, которых
# здесь ещё нет.
#
# Можно подключить несколько файлов сразу: в GLOSSARY_PATH укажите список
# путей через запятую — термины и пары из всех файлов объединяются.
#
# Пример (скопируйте этот файл в glossary.txt и отредактируйте под себя):

# Явная пара: ASR слышит «АИБ», канон — «ОИБ».
АИБ = ОИБ

# Обычные термины.
ОИБ
КИСУСС
информационная безопасность
транскрибер
диаризация
ASR
